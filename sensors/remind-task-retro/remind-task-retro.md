# Entrega feita: rode a retro

O PR está indo para revisão, então a tarefa foi entregue. Rode a skill `task-retro` agora, enquanto a
sessão ainda tem o contexto.

Ela ranqueia os turnos que foram retrabalho evitável, separa **falha de lembrança** (uma regra ou memória
já tinha a correção e ela não foi aplicada) de **pegadinha nova** e, o principal, aponta o documento
exato a editar ou o sensor a criar para o mesmo desperdício não voltar.

Não bloqueia e dispara em todo `gh pr ready`. Se a tarefa foi pequena demais para valer uma retro, diga
isso e siga.
